# Zhihui Song · 个人主页

个人介绍、近期开源贡献、项目展示与联系入口，使用原生 HTML、CSS 和 JavaScript 构建，适配桌面与手机，支持键盘导航和减少动态效果偏好。

## 本地预览

在仓库目录运行 `python -m http.server 8080`，打开 `http://localhost:8080`。

## 内容维护

- `index.html`：个人介绍、近期开源贡献及状态、项目链接、电子邮箱及页面元信息。
- `style.css`：配色、排版与响应式布局。
- `script.js`：页脚年份。
- `favicon.svg`：站点图标。

项目简介来自 GitHub 公开信息；Fork 项目已单独标注。联系方式经本人提供。

## 发布

GitHub Pages 从 `main` 分支根目录发布，无需安装依赖或构建。`.nojekyll` 让静态文件直接发布。

`CNAME` 保留现有自定义域名配置。域名或 HTTPS 设置应在仓库的 Settings → Pages 中管理。


近期贡献以对应上游 PR 为来源，区分已合并和审查中。更新时核对合并状态及时间，页面日期按北京时间展示。
